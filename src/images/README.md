# Images

Every picture used by the website lives in this folder.

The easiest way to add your photos is to replace these files with your own images while keeping the same filenames:

- `hero.jpg` — the large opening photo
- `memory-1.jpg`
- `memory-2.jpg`
- `memory-3.jpg`
- `social-preview.png` — the preview card shown when the website link is shared

If you use different filenames, update the four import lines at the top of `src/content.ts`.
