# Add albums here

Create one folder for each album and place the album's images inside it.

Example:

```text
albums/
  Beach Trip 2026/
    sunset.jpg
    us-by-the-water.jpg
  Anniversary Dinner/
    dinner.jpg
```

The folder name automatically becomes the album title on the website. Supported
image formats are JPG, JPEG, PNG, WEBP, AVIF, and GIF.
